# Decisions Log

Every judgement call, guessed number, or simplified mechanic goes here.
Newest at the bottom. Format:

### D-000: Title

- **Date:** YYYY-MM-DD
- **Phase:** N
- **Decision:** what I chose
- **Why:** reason / source
- **Confidence / how wrong it might be:** e.g. exact, ±10%, pure guess
- **Revisit when:** trigger for reconsidering (optional)
